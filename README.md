# Генератор таджикских субтитров (CapCut / After Effects / SRT)

Разработчик: **[hafizoff dev](https://www.instagram.com/hafizoff.dev?mdxt=MWsxcmxiOGNndnBuaQ==)**

Кроссплатформенное десктопное приложение (**Windows** и **macOS**) с поддержкой **таджикского языка (Тоҷикӣ)** (включая смешанную речь с арабскими вставками, аятами и хадисами) для точной привязки текста к голосу и создания нативных анимированных субтитров в **CapCut Desktop**, **Adobe After Effects** и `.SRT`.

## Возможности
- **Поддержка таджикского языка (Тоҷикӣ):** нативная работа с таджикской кириллицей (`ғ`, `қ`, `ҳ`, `ӣ`, `ҷ`, `ӯ`) и точная синхронизация даже при смешанной речи с арабскими фразами на базе нейросети Meta MMS (`tgk`).
- **Нативная интеграция с CapCut Desktop:** записывает субтитры напрямую в таймлайн проекта с пословными таймингами и умной разбивкой по предложениям и паузам — работают все встроенные шаблоны и пословная подсветка.
- **Экспорт для Adobe After Effects (`.JSX`):** генерирует готовый скрипт, создающий на таймлайне композиции отцентрированные текстовые слои, расставленные по голосу.
- **Экспорт в `.SRT`:** сохранение стандартных файлов субтитров для Premiere Pro, DaVinci Resolve и YouTube.
- **Встроенный промпт для Gemini:** позволяет в один клик получить точную транскрипцию смешанной речи без таймкодов.

## Системные требования
- **Операционная система:** Windows 10 / 11 (64-bit) или macOS 12+ (Intel и Apple Silicon M1/M2/M3/M4)
- **Оперативная память (RAM):** минимум **8 ГБ** (на Windows при включённом файле подкачки от 8 ГБ), рекомендуется **16 ГБ**
- **Ускорение (GPU):** автоматически использует **NVIDIA CUDA** на Windows или **Apple Metal (MPS)** на Mac M1/M2/M3/M4; также работает на обычном процессоре (CPU)
- **Место на диске:** **6–8 ГБ** свободного места

## Установка и запуск

### Windows
1. Скачайте репозиторий (**Code -> Download ZIP**) и распакуйте в любую папку.
2. Запустите **`install.bat`** — скрипт **автоматически установит Python 3.11** (если он ещё не установлен), создаст виртуальное окружение и установит все библиотеки.
3. Для запуска используйте **`run.bat`**.

### macOS
1. Скачайте репозиторий (**Code -> Download ZIP**) и распакуйте архив.
2. Откройте Терминал в папке программы (правый клик по папке -> *Новая вкладка Терминала по адресу папки*) и выполните команду, чтобы снять блокировку безопасности macOS и запустить установку:
   ```bash
   xattr -cr . && chmod +x install.command run.command && ./install.command
   ```
   *(Альтернатива без Терминала: при появлении окна «Apple не удалось подтвердить...» нажмите «Готово», откройте **Системные настройки -> Конфиденциальность и безопасность**, пролистайте вниз и нажмите **«Всё равно открыть»**).* 
3. После завершения установки запускайте программу двойным кликом по **`run.command`**.

## Как пользоваться
1. Нажмите **«Копировать промпт»** в приложении и отправьте его вместе с вашим видео/аудио в Gemini, чтобы получить чистый текст.
2. **Для CapCut:** откройте проект в CapCut Desktop, нажмите **Текст -> Автосубтитры -> Создать** (на любом языке) и выйдите в главное меню CapCut. Вставьте текст в приложение и нажмите **«Отправить в CapCut»**.
3. **Для After Effects:** нажмите **«After Effects (.JSX)»**, выберите видео/аудио и сохраните скрипт. В After Effects откройте композицию и выберите **File -> Scripts -> Run Script File...**.
4. **Для .SRT:** нажмите **«.SRT»** для сохранения стандартного файла субтитров.
